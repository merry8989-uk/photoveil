Invisible armour
for your photos.

AI editors can now rebuild a photo you posted — swap a face, change a scene, remove a person. PhotoVeil adds a shield to the pixels that you cannot see, and that an image model cannot cleanly step around. It runs entirely on your phone: nothing is uploaded, nothing is logged, no account is needed.

How the shield works

The idea is borrowed from PhotoGuard (Salman et al., Raising the Cost of Malicious AI-Powered Image Editing): push the image into a region of pixel space where a diffusion model's encoder no longer lands on the thing you photographed. PhotoGuard does that with gradients through Stable Diffusion's VAE on a GPU. A phone has neither, so PhotoVeil takes the gradient-free route.

A

Band-shaped noise

A seeded, deterministic noise field is split: half low-passed with a five-tap kernel, half high-passed with a Laplacian. That puts energy where a VAE's 8× downsampling folds detail back into the latent, and keeps a share of it in the band that survives re-encoding.

B

Texture-masked

Amplitude follows local texture. Busy areas absorb it invisibly; flat gradients like skin and sky get the least. The eye forgives noise where there is already detail.

C

Clamped, not faded

The per-pixel delta is clamped to the room the pixel actually has, so a near-white pixel gets a downward nudge instead of being skipped. No banding, no blown highlights, no dead zones.

What is in the app

Shield tab

  • Pick up to 10 photos at once and shield them in a batch
  • Three modes: Standard, Strong, and Visible (adds a faint repeated stamp)
  • Strength slider, with the real amplitude in /255 shown live
  • Per-image report: mean change, largest change, pixels touched, noise floor before → after, compute time
  • Share straight to any app, or copy into the device gallery

Vault tab

  • Every shielded image is kept in the app's own folder
  • Thumbnails, file size and timestamp for each
  • Share or delete any of them, with a confirmation before deleting
  • Refresh on demand; nothing is synced anywhere

Check tab

  • Pick the original and the file you hold now
  • Mean difference, share of pixels differing, and how fine-grained the difference is
  • Verdict: shield intact, no shield between these files, or the image was edited
  • File details: dimensions, noise floor, whether EXIF and GPS survived

Settings and upkeep

  • Theme (light / dark / system), five accent colours, text size and density
  • Shield defaults: mode, strength, fresh seed per image, visible-stamp text
  • Output: PNG or JPEG, JPEG quality, largest side (2048–6000 px), save to gallery, auto-share
  • Diagnostics: log collection on by default, export as .txt / .json / .md / .zip, share, clear
  • In-app updates: checks the latest GitHub Release and installs it without a browser

Install

1

Download the APK

Grab the latest signed release from GitHub Releases. Every build is produced and signed by GitHub Actions from this repository's source.

2

Allow the install

Android will ask you to allow installs from your browser or file manager the first time. That is the normal side-loading prompt — the APK is signed, and the signature never changes between versions.

3

Updates come from inside the app

Settings → About → Check for updates reads the latest GitHub Release, downloads the APK and hands it to the installer. It installs over the current version, so you never uninstall first.

Requires Android 8.0 (API 26) or newer. Package ID io.github.merry8989uk.photoveil. Builds from source: ./gradlew assembleDebug.

What it does not do

Read this before you trust it with something that matters

  • It is a deterrent, not a lock. A determined person with a good model can still edit your photo. The shield raises the cost and the visible damage; it does not make editing impossible.
  • JPEG erodes it. Measured here: a re-save at quality 90 removes a large part of the perturbation. That is true of any invisible shield. If you can, share the PNG the app gives you.
  • Resizing destroys it. Any crop, scale or screenshot-and-repost resamples the pixels and takes the shield with it.
  • It does not stop training scrapes. A model trained on a web-scale crawl will still see your image. This protects a specific file against a specific kind of editing, not your whole online presence.
  • The check tab measures, it does not prove. It reports a real number and a verdict with stated limits. A high-ISO photo and a shielded photo can look alike.

Credit where it is due: the approach follows PhotoGuard by Hadi Salman, Alaa Khaddaj, Guillaume Leclerc, Andrew Ilyas and Aleksander Madry (arXiv:2302.06588). This project shares the idea, not the code — the implementation here is a gradient-free on-device engine written from scratch in Kotlin and JavaScript.
